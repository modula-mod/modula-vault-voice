# Vault Voice

Microphone recording and governed transcription add-on for Vault Notes.

Audio is captured only when the user records. Temporary buffers are not a second database. Transcription uses a provider-neutral engine and must not fake output when unconfigured.

Published ID remains `digital.modula.vault-notes.voice`.

The product owns its recording/playback/transcription contributions, settings, permission explanation, and provider-unavailable presentation in a validated MPS frontend artifact. The host owns native audio capture and permission prompts through `audio.capture@1`.
