# Privacy

| Topic | Truth |
| --- | --- |
| Capture | Microphone, user-initiated |
| Storage | Recordings as add-on-owned object storage; notes remain Vault Notes records |
| Transmission | `voice.transcribe` engine only when configured |
| Retention | Until user delete or uninstall deleteData |
| Deletion | Supported |
| Analytics | None |

Do not log audio, transcripts, or credentials.
